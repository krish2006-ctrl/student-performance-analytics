# Student Performance Analytics System

A Python data analytics system built using NumPy and Pandas to evaluate student academic metrics, assign grades, and compute key performance insights.

## Project Structure
- `students.csv`: Dataset containing student records, marks across 3 subjects, and attendance.
- `functions.py`: Modular functions for mark calculations, grading rules, and statistics.
- `main.py`: Main executable file that processes data and outputs summary analytics.
- `Project_Documentation.md`: Detailed report covering methodology, implementation, and outcomes.
